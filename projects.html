Dynamic Island for macOS — Native Swift Desktop Application

A native macOS Dynamic Island in Swift (AppKit and SwiftUI, SwiftPM, no Xcode required) that lives in the notch. It shows Spotify's now playing off the app's own broadcast instead of polling, holds a drag-and-drop staging vault, mirrors a real folder on disk through FSEvents so there is never a second copy of the state, and runs an on-device voice assistant that creates calendar events from natural speech or opens an Obsidian vault — all processed on device.

The part I'm most proud of is chasing down a real performance problem. The first version invalidated the entire view tree on every filesystem event, and thumbnails were decoded at full size synchronously on the main thread. I rewrote the observation graph so each view only subscribes to what it reads, moved thumbnail decoding off the main thread with proper downsizing, and pushed file I/O onto background queues — median CPU under sustained filesystem churn dropped from about 15% to about 4%, roughly 3.7x. The same benchmark later caught a regression where a debounce change that looked like a clean win had silently broken the file listener.

Market-Making Simulator — Quantitative Finance & Market Microstructure

A Python limit order book simulator built to study market-making, inventory risk, adverse selection and execution. Implements four market-making strategies — including Avellaneda–Stoikov and GLFT — and calibrates fill intensity from simulated order flow rather than assuming model parameters. Multi-regime experiments compare PnL, drawdown, inventory, markout and risk-adjusted returns, with 80 tests covering order-book mechanics, accounting, calibration and closed-form quoting formulas.

Monte Carlo Quant Lab — Quantitative Finance & Risk Simulation

A from-scratch Python framework exploring Monte Carlo methods in quantitative finance, covering option pricing, exotic derivatives, variance reduction and portfolio risk. Implements GBM simulations, Asian option pricing, antithetic variates, Cholesky-based correlated simulations, and VaR/CVaR, with results systematically validated against Black–Scholes and other closed-form solutions. Built with NumPy, SciPy, Matplotlib and Pytest.
