dynamic-island-macos

Swift, AppKit + SwiftUI

A right-anchored Dynamic Island for macOS that lives in the notch. Spotify now-playing off the app's own broadcast rather than polling, a drag-and-drop staging vault, and a folder mirrored live through FSEvents so there's never a second copy of the state. Native, SwiftPM, no Xcode required.

The part worth talking about is a performance fix: the first version invalidated the whole view tree on every filesystem event and decoded thumbnails at full size on the main thread. Rewriting the observation graph and moving decoding off the main thread took median CPU under sustained churn from about 15% to about 4%.
